# 2025년 천안시 데이터 분석 아이디어 경진대회

개인 담당 파트 관련 정리 및 파일 저장 위치: [HanJaeHui-Github/ESAA/OB/방학 프로젝트](https://github.com/HanJaeHui-GitHub/ESAA/tree/main/OB/%EB%B0%A9%ED%95%99%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8)

## 주제 : 천안시 노인 복지 사각지대 제로화를 위한 고위험군 예측 기반 정책 제안

지정과제 중 '[복지/사회] - 천안시 복지/사회 활성화 관련 데이터 분석 및 정책제언' 선택

## 분석 단계

**1. 데이터 기반 현황 분석 및 세부 지표 구축(전처리)**

   천안시의 복지 현황에 대한 다차원적 세부지표 구축.

   인구, 경제, 시설 등 행정동별 고유 특성을 반영한 세부 지표 가공을 통한 복지 사각지대 다각적 조망을 위한 분석 기반 마련
  
**2. 복지 사각지대 위험지 도출 및 취약 요인 규명(모델링)**

   인자 분석 - 행정동별 복지 사각지대 위험 점수 산출

   공간 자기상관 분석 - 복지 사각지대 위험지 도출

   K-Means 군집 분석 - 천안시 복지 사각지대 위험지를 고위험/중위험/저위험으로 분류

**3. 분석 기반 정책 타당성 제시 및 시각적 현황 표현(시각화)**

   위험군별 취약 인자 규명을 통한 복합적 위험 요인 판단

   위험지 분류를 통한 천안시 노인 복지 정책 및 향후 계획의 타당성 확보와 구체화 기여

   분석 결과의 태블로 대시보드 시각화를 통한 천안시 현황의 직관적 표현과 정책 의사결정 지원 도구 제시
